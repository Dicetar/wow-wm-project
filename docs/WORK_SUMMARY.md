This repository is now a real WM platform baseline for a per-character World Master progression engine, not just an idea pile.

The intended product direction is personal arcs, exclusive rewards/unlocks, item-granted powers, visible shell powers, companion behavior, deployables/live scenes, random enchant/rune systems, conversation steering, and locked-contract LLM proposal mode. Platform work is a gate for those outcomes, not the roadmap center.
